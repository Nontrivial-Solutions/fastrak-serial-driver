The collection of architectural decision records for the system.

The acceptance status of each ADR is indicated by the following icons:

- Suggested (:fontawesome-solid-clipboard-question:): The initial state of a proposal.
- In Progress (:fontawesome-solid-hourglass-half:): The proposal has been accepted in principle
    but isn't complete.
- Accepted (:fontawesome-solid-check:): The proposal is accepted.
- Rejected (:fontawesome-solid-x:): The proposal has been rejected.
- Deprecated (:fontawesome-solid-skull:): The decision has been deprecated.
