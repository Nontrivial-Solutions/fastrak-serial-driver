## Goals

The use case models the initialization of a Fastrak.

### Happy Outcome

When the use case completes successfully the Fastrak is initialized.

### Sad Outcome

When the use case completes unsuccessfully a failure is handled.

## Preconditions

- A serial device is connected.

## Actors

- [User](../actors/00001_user.md)

## Trigger

A user requests the initialization of a Fastrak device.  

## Scenario

1. The user requests device initialization
1. The serial device is verified
1. The serial commands for initialization are sent
1. The serial commands for boresight are sent
1. An error occurs:
    1. Set error state
    1. Report a disconnect or init error
