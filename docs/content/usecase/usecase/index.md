The collection of system use cases.

The priority of the use case to the stakeholders is indicated by the following icons:

- Critical (:fontawesome-solid-angles-up:): The use case is so important that missing it means the
    product isn't just incomplete it's straight up unusable. The use case should be realized before
    anything else.
- High (:fontawesome-solid-angle-up:): The use case is important for the product, missing this use
    case means the product is incomplete. The use case must be realized.
- Medium (:fontawesome-solid-angle-down:): The use case is needed for the product but not a
    showstopper. The use case should be realized when practical.
- Low (:fontawesome-solid-angles-down:): The use case would be useful but everything else should
    be completed before it is realized.
